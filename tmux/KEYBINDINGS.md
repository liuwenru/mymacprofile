# tmux 快捷键速查

对应同目录 `tmux.conf`（tmux 3.8），内容取自 `tmux list-keys` 的实际生效结果，包含本配置自定义键和仍然有效的 tmux 默认键。

- **前缀键**：`Ctrl-j`（默认的 `Ctrl-b` 已取消）。下文的"前缀"都指先按 `Ctrl-j` 再按后面的键。
- **编号**：窗口和 pane 都从 1 开始，关闭窗口后自动重新编号。
- **可连按**：标了"可连按"的键，按一次前缀后 300ms 内可以重复按，不用再按前缀。
- **查询**：`前缀 + ?` 列出全部绑定，`前缀 + /` 再按某个键可查看它绑定了什么。

## 窗口（window）

| 按键                        | 作用                                             |
| --------------------------- | ------------------------------------------------ |
| `前缀 + c`                  | 新建窗口                                         |
| `前缀 + 1` ~ `9`            | 跳到 1~9 号窗口                                  |
| `前缀 + '`                  | 输入编号跳转，10 号及以后的窗口用它（如输入 11） |
| `前缀 + w`                  | 窗口列表，方向键或 `j/k` 选择后回车              |
| `前缀 + n` / `前缀 + p`     | 下一个 / 上一个窗口（`Ctrl-n` / `Ctrl-p` 同效）  |
| `前缀 + l`                  | 回到上一次所在的窗口（tmux 默认键）              |
| `前缀 + Alt-n` / `Alt-p`    | 下一个 / 上一个有提醒的窗口                      |
| `前缀 + f`                  | 按名称或内容搜索窗口                             |
| `前缀 + ,`                  | 重命名当前窗口                                   |
| `前缀 + .`                  | 把当前窗口移动到指定编号                         |
| `前缀 + &`                  | 关闭当前窗口（需确认）                           |

## 面板（pane）

### 分屏与关闭

| 按键                    | 作用                                   |
| ----------------------- | -------------------------------------- |
| `前缀 + \|`             | 左右分屏，新 pane 继承当前目录         |
| `前缀 + -`              | 上下分屏，新 pane 继承当前目录         |
| `前缀 + x`              | 关闭当前 pane（需确认）                |
| `前缀 + !`              | 把当前 pane 拆出去成为独立窗口         |
| `前缀 + +` 或 `前缀 + z` | 最大化 / 还原当前 pane                 |

默认的 `"` 和 `%` 分屏键已取消。

### 切换焦点

| 按键                     | 作用                                |
| ------------------------ | ----------------------------------- |
| `前缀 + h / j / k`       | 切到左 / 下 / 上的 pane，可连按     |
| `前缀 + 方向键`          | 切到对应方向的 pane，可连按         |
| `前缀 + ;`               | 回到上一次所在的 pane               |
| `前缀 + q`               | 显示 pane 编号并一直停留，按数字跳转，按 `Esc`、`q` 或其他任意键退出 |

切到右侧 pane 只能用 `前缀 + →`（`前缀 + l` 已改回 tmux 默认的"回到上一个窗口"）；默认的 `前缀 + o`（切到下一个 pane）已取消。

### 调整大小

| 按键                     | 作用                                  |
| ------------------------ | ------------------------------------- |
| `前缀 + H / J / K / L`   | 向左 / 下 / 上 / 右调整 5 格，可连按  |
| `前缀 + Alt-方向键`      | 每次 5 格，可连按                     |
| `前缀 + Ctrl-方向键`     | 每次 1 格，可连按                     |

### 交换与旋转

| 按键                      | 作用                               |
| ------------------------- | ---------------------------------- |
| `前缀 + >` 或 `前缀 + }`  | 当前 pane 与下一个交换位置         |
| `前缀 + <` 或 `前缀 + {`  | 当前 pane 与上一个交换位置         |
| `前缀 + Ctrl-o`           | 窗口内所有 pane 整体向前轮转一位   |
| `前缀 + Alt-o`            | 反方向轮转                         |

### 布局

| 按键             | 作用                                              |
| ---------------- | ------------------------------------------------- |
| `前缀 + 空格`    | 在预设布局间循环切换                              |
| `前缀 + Alt-1`   | 左右均分：所有 pane 排成一行，宽度相等            |
| `前缀 + Alt-2`   | 上下均分：所有 pane 排成一列，高度相等            |
| `前缀 + Alt-3`   | 主次布局：上方一个大 pane（占 65%），其余排在下方 |
| `前缀 + Alt-4`   | 主次布局：左侧一个大 pane（占 65%），其余排在右侧 |
| `前缀 + Alt-5`   | 平铺：按网格排列，各 pane 大小接近                |
| `前缀 + Alt-6`   | `Alt-3` 的镜像：大 pane 在下方                    |
| `前缀 + Alt-7`   | `Alt-4` 的镜像：大 pane 在右侧                    |
| `前缀 + E`       | 把各 pane 均匀摊开                                |

`Alt-1..7` 在本配置里做了三点调整（`Alt-5` 除外）：

- **再按一次切到同组另一个**：`Alt-1` / `Alt-2` 一组，`Alt-3` / `Alt-6` 一组，`Alt-4` / `Alt-7` 一组。当前已经是该键的布局时，再按同一个键就换成同组的另一个。
- **单 pane 自动分屏**：窗口只有一个 pane 时，先分出一个新 pane（继承当前目录）再套用布局。
- **不依赖 Alt 的等价键**：Mac 终端没有开启"Option 当 Meta 键"时，`Option-1..7` 发出的是字符 `¡ ™ £ ¢ ∞ § ¶`（美式键盘布局），这些字符也绑了同样的功能，所以 `前缀 + Option-数字` 直接可用。

### 浮动 pane（tmux 3.8）

| 按键         | 作用                               |
| ------------ | ---------------------------------- |
| `前缀 + *`   | 新建一个浮动 pane                  |
| `前缀 + @`   | 当前 pane 在浮动和平铺之间切换     |
| `前缀 + g`   | 进入移动模式，状态栏出现提示，再按下面的键移动浮动 pane |

`前缀 + g` 之后可以连按（一直停在移动模式，按 `Esc` 等其他键退出）：

| 按键              | 作用                                         |
| ----------------- | -------------------------------------------- |
| `h / j / k / l`   | 向左 / 下 / 上 / 右移动，每次 3 格           |
| `H` / `L`         | 变窄 / 变宽 3 列（左上角不动）               |
| `K` / `J`         | 变矮 / 变高 3 行（左上角不动）               |

`前缀 + g` 之后按一次即退出的键：`1` / `2` / `3` / `4` 移到左上 / 右上 / 左下 / 右下，方向键贴到对应一边居中，`0` 铺满窗口，`,` 弹出移动菜单，`.` 弹出"移动并调整大小"菜单；按其他键退出。

## 会话（session）

| 按键                    | 作用                         |
| ----------------------- | ---------------------------- |
| `前缀 + Ctrl-c`         | 新建会话                     |
| `前缀 + Ctrl-f`         | 输入会话名查找并切换         |
| `前缀 + s`              | 会话列表                     |
| `前缀 + (` / `前缀 + )` | 上一个 / 下一个会话          |
| `前缀 + $`              | 重命名当前会话               |
| `前缀 + d`              | 脱离会话（会话在后台保留）   |

## 复制与粘贴

复制模式使用 vi 按键，复制内容通过 OSC 52 传给外层终端的剪贴板。

| 按键                       | 作用                                             |
| -------------------------- | ------------------------------------------------ |
| `前缀 + [`                 | 进入复制模式                                     |
| `前缀 + PageUp`            | 进入复制模式并向上翻一页                         |
| `v`（复制模式内）          | 开始选择                                         |
| `y` 或 `Enter`（复制模式内） | 复制并退出复制模式                               |
| 鼠标拖选                   | 松开即复制并退出复制模式                         |
| `前缀 + ]`                 | 粘贴最近一次复制的内容                           |
| `前缀 + =`                 | 从复制历史中选择一条粘贴                         |
| `前缀 + m`                 | 开关 tmux 鼠标；关闭后可用外层终端自己的选择复制 |

## Scratch 弹窗

| 按键             | 作用                                        |
| ---------------- | ------------------------------------------- |
| `前缀 + Ctrl-l`  | 弹出 / 隐藏当前窗口的 scratch 临时会话      |

每个窗口一个 scratch 会话，隐藏后会话保留，窗口关闭时自动清理。由 `tmux.conf` 里的原生绑定实现，不再依赖插件。

## 插件

| 按键             | 作用                                        |
| ---------------- | ------------------------------------------- |
| `前缀 + Ctrl-s`  | 保存会话布局（tmux-resurrect）              |
| `前缀 + Ctrl-r`  | 恢复上次保存的会话布局                      |
| `前缀 + I`       | 安装 `tmux.conf` 中声明的插件（TPM）        |
| `前缀 + U`       | 更新插件                                    |
| `前缀 + Alt-u`   | 清理未声明的插件                            |

## 其他

| 按键                                | 作用                                         |
| ----------------------------------- | -------------------------------------------- |
| `前缀 + r`、`前缀 + u`、`前缀 + Ctrl-u` | 重新加载 `~/.tmux.conf`                      |
| `Ctrl-l`（不按前缀）                | shell 清屏，并清空该 pane 的 tmux 滚动历史   |
| `前缀 + Ctrl-j`                     | 把一个 `Ctrl-j` 发给 pane 内程序（嵌套 tmux） |
| `前缀 + :`                          | 打开 tmux 命令行                             |
| `前缀 + t`                          | 显示时钟                                     |
